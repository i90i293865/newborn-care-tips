# 输卵管超声造影

> 更新时间：2026-09-11 (UTC+8)

输卵管超声造影

输卵管超声造影是通过将造影剂经宫颈注入子宫腔内，在超声监测下，实时动态观察造影剂在子宫及输卵管的充盈和流动性。它可以判断输卵管是否通畅，并可以显示子宫腔、输卵管的形态，清晰地观察子宫黏膜下肌瘤、内膜息肉、内膜粘连，输卵管积水等情况，有利于诊断子宫畸形、子宫内膜息肉、宫腔粘连等宫腔病变。相比传统的X线输卵管碘油造影，超声造影使用的造影剂很少发生过敏，且造影剂无毒、副作用，对肝脏、肾脏无损害；检查过程中不产生辐射；检查结束后，次月即可备孕，是目前不孕症患者输卵管通畅性检查的主要手段之一。

**1**

**在进行输卵管超声造影前，需要做以下准备：**

1. 检查当月禁止同房。

2. 月经干净1-3天尽早来医院挂号完成造影前检查，包括分泌物、血液检查、心电图等，医生评估能否进行输卵管造影检查。

3. 检查时间一般为月经干净3-7天。

4. 完善检查后携带门诊医嘱至门诊手术室预约。

5. 根据预约来院检查，做检查当日穿宽松衣物，方便穿脱，准备卫生巾检查完成后使用。

**2**

**输卵管超声造影术后需要注意以下事项：**

1. 造影后禁盆浴及性生活两周，可酌情给予抗生素预防感染。

2. 有时因输卵管痉挛造成输卵管不通的假象，必要时重复进行。

3. 造影检查后一周内有少量阴道出血如无其它不适属正常现象，如出血量较多超过月经量或有其它不适应该及时就诊。

4. 注意多休息和保暖，避免劳累和着凉，以免影响恢复。

5. 加强营养，多吃富含营养的食物，如热牛奶、米粥、肉汤等，以促进身体恢复。
